# Simple Math

A calm, responsive 8th-grade math study app built with plain HTML, CSS, and JavaScript. Open `index.html` in a browser to use it; no build step or dependencies are required.

## Features

- Five color-coded units with topic filters and concise lessons, formulas, worked examples, hints, and gentle practice feedback.
- Focus Mode to hide distractions.
- Live slope, Pythagorean theorem, 3D volume, and transformation visualizers.
- Local browser Study Tracker for mastered topics, personal notes, and a “Things to Work On” list.
- Pastel confetti and a customizable, printable graduation certificate.

Progress and notes are stored locally in the browser using `localStorage` and are not uploaded.
